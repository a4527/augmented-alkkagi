- GitHub Actions는 커밋 SHA로 고정돼 있다. SHA로 고정한 액션에 알림이 오는지는 확인하지 않았다. 액션 갱신도 정기 패치에서 확인한다.
- #8의 시간 초과가 갱신 때문인지 CI 속도 때문인지는 확인하지 않았다(MNT-001).
