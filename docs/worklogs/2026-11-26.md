- GitHub Actions는 커밋 SHA로 고정돼 있다. SHA로 고정한 액션에 알림이 오는지는 확인하지 않았다. 액션 갱신도 정기 패치에서 확인한다.
- #8의 시간 초과가 갱신 때문인지 CI 속도 때문인지는 확인하지 않았다(MNT-001).

### 한계·미검증

- **HostHatch**:
  - 위치별 월 가격, 결제 주기(월 단위 가능 여부), 한국 부가세, 공유 CPU 약관을 확인하지 못했다. 가격 조회에 가입·카드 등록이 필요해 OPS-004의 주문 전 확인 기준으로 넘겼다.
  - 사용자가 붙여 준 "Seoul $4.00" 목록은 제3자 가격 추적 사이트 정보라 참고로만 쓴다.
- **추정치(측정 안 함)**: 메모리(OS·Caddy·Node·PostgreSQL·Alloy), 스냅샷 크기(1KB 가정)·월 전송량, 동시 경기 처리량, 한국–서울/도쿄 왕복 지연(일반 수준 10~40ms)은 측정하지 않았다(OPS-004·VAL-003).
- **지연 기준 출처**: 지연 기준은 Claypool의 장르별 허용치(1인칭 약 100ms, 3인칭·스포츠 약 500ms, 전략 약 1000ms)를 Claude가 기억으로 인용했다. 논문 원문은 이번에 다시 읽지 않았다. VAL-003의 지연 주입 실험으로 이 게임에 맞는지 확인한다.
- **Grafana Cloud**: 요금 페이지에 요금 체계 변경 예고 문구가 있어 도입 때 다시 확인해야 한다.
- **Supabase**: 무료 플랜의 서울 선택 가능 여부를 확인하지 못했다.
- **R2·pgBackRest**: R2 카드 필요 여부와 pgBackRest–R2 호환은 확인하지 않았다.
