### 정정: 문서 형식 검사

DOC-013·DOC-014 기록과 PR #1·#3·#4 본문에 적은 "`npx prettier --check` 통과"는 실제 검사가 아니었다. `config/prettier.ignore`가 `*.md`·`docs`·`*.html`을 제외하므로 `--ignore-path`를 붙인 검사는 대상 파일 0개로 "All matched files use Prettier code style!"을 출력했다. ignore 없이 검사하면 AGENTS·README·TASKS·DECISIONS 등은 변경 전(`76a9d5c`)에도 Prettier 형식과 달라 경고가 나오므로, 이 저장소에서 Markdown 형식은 강제 대상이 아니다. 이번 작업들의 문서 검증 근거는 상대 링크·앵커 스크립트 대조와 내용 비교다.
