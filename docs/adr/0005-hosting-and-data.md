# ADR-0005: 운영 인프라(호스팅·DB·백업)

DEC ID: [DEC-098](../DECISIONS.md#결정-색인)
결정일: 2026-11-26
상태: 승인
동의 근거: 2026-11-26 사용자 메시지 "oracle vm이 회수가 가능한게 좀 위험한거 같아 초반엔. 다른 방법은 없을까? 월 만원이하면 괜찮을거같아", "vultr 메모리 2기가로 올려도 5달러 요금 있는거같은데 찾아보고 만약 비싸면 supabase도 고려해야할것같아", "도쿄면 괜찮을거같은데", 조건부 기록안에 "그러자 기록해". 서울 우선, 자체 Postgres, R2 백업, 대체안 조건은 Claude가 제안했다.
대체 관계: [ADR-0003](0003-tech-stack-and-architecture.md)의 배포(Render 무료 웹 서비스 + 절전 방지 요청)와 저장 서비스(Neon 무료) 선택을 대체한다. [DEC-029](../DECISIONS.md#결정-색인)·[DEC-047](../DECISIONS.md#결정-색인)·[DEC-094](../DECISIONS.md#결정-색인) ③·④도 대체한다.

## 배경

ADR-0003의 구성은 "지인 10명, 월 0원, 첫 접속 5초"를 기준으로 골랐다. 2026-11-26에 기준이 바뀌었다.

- **배포 채널**: 자체 도메인 서버를 운영하면서 itch.io·CrazyGames에 클라이언트를 제출한다([DEC-097](../DECISIONS.md#결정-색인)). 포털이 정적 파일을 서비스하므로 서버는 API·WebSocket을 맡는다.
- **운영 기준**([DEC-096](../DECISIONS.md#결정-색인), [PRD](../PRD.md#4-비기능-요구사항과-제약)):
  - 동시 접속 최대 50명, 24시간 이용
  - 가동률 95%, 장애 복구 24시간
  - 가입 계정과 전적 손실 없음
  - 월 1만 원 이하
  - 주 1시간 운영
- **기존 구성이 맞지 않는 이유**:
  - Neon 무료 플랜은 월 100 CU-hour다. 24시간 이용이면 최소 크기(0.25 CU)로도 월 약 186 CU-hour가 필요하다. 한도를 넘으면 그달 말까지 컴퓨트가 정지되고 `pg_dump`도 실패한다.
  - Neon의 접속이 없어도 세션 저장소의 15분 주기 정리가 컴퓨트를 깨운다.
  - Render 무료 플랜의 제약:
    - CPU 0.1개
    - 15분 절전 뒤 깨어나는 데 약 1분
    - 월 외부 전송 5GB
    - 롤백은 직전 2개까지
    - 절전 방지 요청은 이용 정책의 "사용 제한 우회 금지"에 걸릴 수 있다

후보 비교와 출처·확인일은 [2026-11-26 worklog](../worklogs/2026-11-26.md#ops-002-운영-인프라-재검토)에 있다.

## 선택과 핵심 조건

1. **서버**: HostHatch 2GB VM(AMD EPYC 공유 1코어, NVMe 10GB, 월 1TB)
   - **위치**: 서울(KINX 도곡)을 우선하고 도쿄(Equinix TY8)를 차선으로 한다.
   - **가격**: 공개 가격은 "from $4.00 / month"다. 위치별 가격은 가입 뒤 콘솔에서만 보인다.
   - **주문할 때 확인할 조건**:
     - 월 결제가 가능하다.
     - 부가세와 도메인을 포함해 월 1만 원 이하다.
     - 공유 CPU 약관에 상시 사용 제한이 없다.
   - **대체안**: 위 조건 중 하나라도 어긋나면 Vultr 서울 `vc2-1c-1gb`($5)에 Supabase 무료(서울)와 1시간마다 R2 덤프를 둔다.
2. **도메인과 앞단**: 자체 도메인을 Cloudflare 무료로 운영한다.
   - Cloudflare가 DNS, 프록시, TLS, WebSocket 중계를 맡는다.
   - 포털 빌드에 고정되는 서버 주소를 도메인으로 두어 호스팅을 바꿔도 다시 제출하지 않게 한다.
3. **실행**: VM 안에서 Docker Compose로 다음을 함께 실행한다.
   - Caddy(TLS 종단)
   - Node 서버
   - PostgreSQL
   - Grafana Alloy(모니터링 에이전트, [DEC-099](../DECISIONS.md#결정-색인))

   메모리는 추정이므로 구축 때 측정한다.
4. **DB**: 같은 VM의 PostgreSQL이 Neon을 대체한다.
   - 사용 시간 한도와 서버–DB 사이 지연이 없어진다.
   - 게스트는 저장하지 않으므로 DB에는 가입 계정, 전적, 세션 같은 지킬 데이터만 남는다.
5. **백업**:
   - **변경 기록**: DB 변경 기록(WAL)을 1분 안팎 간격으로 Cloudflare R2(무료 10GB)에 보관한다. 시점 복구를 쓸 수 있다.
   - **전체 백업**: 주기적으로 한다.
   - **복구 연습**: 월 1회 임시 컨테이너에 복구해 본다.
   - **손실 범위**: VM이 통째로 사라져도 잃는 데이터는 마지막 보관 이후 약 1분이다.
   - **도구**: pgBackRest를 우선한다(S3 호환 저장소 지원). R2와의 호환은 구축 때 확인한다.
6. **정리**: 새 구성이 가동되면 Render·Neon 운영 서비스와 UptimeRobot의 절전 방지 요청을 끝낸다.
   - 운영 계정은 사용자 본인의 새 계정이다.
   - 기존 Neon 데이터를 옮길지는 미정이다. 기본안은 새로 시작하는 것이다.

## 대안과 절충

2026-11-26에 공식 문서로 확인했다. 상세 근거는 worklog를 본다.

| 대안 | 배제 이유 | 포기한 이점 |
| --- | --- | --- |
| Render 무료 유지 | 절전·CPU 0.1·월 5GB로 포털 이용자를 감당하기 어렵다. 절전 방지 요청은 정책상 회색 지대다 | 카드 없는 0원, 관리 없는 PaaS, CI 통과 후 자동 배포 옵션 |
| Render 유료($7) | 부가세를 포함하면 1만 원을 넘고 메모리 512MB다 | 관리 부담이 가장 적다 |
| Oracle Cloud Always Free(서울) | 유휴 VM 회수 조건이 있다(7일간 CPU·네트워크·메모리 20% 미만). 종량제로 바꿔도 회수가 면제된다는 공식 문구가 없고 지출 상한이 없다 | 0원, 큰 사양, 월 10TB |
| Cloudflare Workers/Durable Objects | Socket.IO(`upgrade` 미지원)와 argon2를 쓸 수 없어 재작성해야 한다. 무료 한도는 동시 약 1경기 수준이다 | 절전이 없고, 한도를 넘으면 청구 대신 오류가 난다 |
| Cloudflare 정적 분리 + Render | Render 절전 문제가 그대로이고 구성 요소만 늘어난다 | 정적 파일 무제한 전송 |
| Railway·Fly.io·Koyeb·Cloud Run·AWS·Azure | Railway는 $1 크레딧으로 상시 실행 불가. Fly.io는 카드 등록 시 자동 청구. Koyeb은 신규 무료 종료. Cloud Run은 상시 인스턴스 비용 발생. AWS는 크레딧이 만료. Azure F1은 WebSocket 5개 제한 | — |
| Vultr 서울 1GB + 자체 Postgres | 1GB에 Node·Postgres·Alloy를 함께 두면 메모리가 빠듯하다. 2GB(`vc2-1c-2gb` $10)는 예산을 넘는다 | 큰 업체, 서울 위치 확정 |
| Supabase 무료 | 무료 플랜에 백업이 없어 직접 덤프해야 하고(손실 최대 덤프 주기), 덤프도 월 5GB 전송에 포함된다. 무료 사양은 "변경될 수 있음"이다 | DB 관리 부담 없음(대체안으로 유지) |
| Neon 무료 유지 | 24시간 이용 시 CU-hour 한도를 넘는다. 유료(Launch)는 월 약 $20이다 | 관리형 시점 복구(6시간) |
| Prisma Postgres·Nile·Aiven 무료 | 무료 백업이 없거나, 디스크가 1GB이거나, 리전이 임의로 바뀔 수 있다 | — |
| CockroachDB Basic | 카드가 필요하고 한도에 걸리면 정지 또는 청구된다. Postgres와 호환성 위험이 있다 | 매일 백업, 30일 보관 |

## 영향과 위험

- **운영 부담 증가**:
  - VM 운영은 OS 보안 패치, 방화벽, Docker 디스크 정리, 인증서, 백업 감시를 직접 해야 한다.
  - 주 1시간 안에 들도록 다음을 자동화한다: 자동 보안 업데이트, 컨테이너 자동 재시작, CI/CD 배포([OPS-003](../TASKS.md#ops-003-배포-자동화)), 알림([OBS-001](../TASKS.md#obs-001-모니터링알림)).
  - 구축 절차와 결과는 [OPS-004](../TASKS.md#ops-004-운영-서버-구축)에 남긴다.
- **작은 업체 위험**:
  - SLA와 지원 수준이 대형 업체보다 약하다.
  - 가동률 목표가 95%이고 복구 기준이 24시간이라 감수한다.
  - 장애가 길어지면 R2 백업으로 대체안 호스팅에 복구한다.
- **디스크 10GB**: Docker 이미지 정리, 로그 순환, 로컬 WAL 보관 상한을 설정한다.
- **단일 서버**:
  - 경기 상태가 메모리에 있어 수평 확장할 수 없다.
  - 한 대의 처리량(동시 25경기 목표)은 [VAL-003](../TASKS.md#val-003-부하e2e-검증)에서 측정한다.
  - 넘으면 VM을 키우거나 동시 경기 상한을 둔다.
- **코드 영향**:
  - 프록시가 Cloudflare와 Caddy 두 단계가 된다. 그래서 `trust proxy`와 클라이언트 IP 판별을 바꾼다(OPS-003).
  - 포털 iframe에서는 쿠키 세션이 전송되지 않는다. 인증 방식 변경은 [POR-001](../TASKS.md#por-001-itchio-배포)에서 다룬다.
- **비용**:
  - 서버 $4~(위치별 가격 미확인)와 도메인 월 약 1,250원(연 1.5만 원 안팎)이 든다.
  - 부가세 부과 여부는 미확인이다.
  - 주문할 때 확정해 worklog에 남긴다.

## 재검토 조건

- 주문할 때 위 조건(월 결제, 월 1만 원 이하, CPU 약관) 중 하나라도 어긋날 때
- 동시 25경기에서 `tick_skipped`가 생기거나 메모리가 부족할 때
- 백업 보관(R2 무료 10GB)이나 복구 연습이 실패할 때
- 가동률이 95%를 밑돌거나 업체 장애가 24시간을 넘을 때
- 이용자가 늘어 수익으로 더 큰 구성을 감당할 수 있을 때([DEC-096](../DECISIONS.md#결정-색인) ⑤)
